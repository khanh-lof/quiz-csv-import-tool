# HSK3 vocabulary index (词语表)

Transcribed visually from the book's own 词语表 (book p.174-182 = PDF p.186-194), per
`common/README.md` section 2 ("never trust OCR for pinyin"). Alphabetical, matching the
book's own A-Z order. **★ = 超纲词** (beyond this level's syllabus — label these
optional/mở rộng on slides, never as required vocabulary).

**Scan-quality note:** PDF page 190 (book p.178, covering the end of J through M) is
physically skewed in the source scan (EPSON Scan flatbed artifact, not a rendering
issue — confirmed via `pdfinfo`). The word/pinyin/number columns drift apart vertically
across that one page. Every entry below was reconstructed using two independent
ground-truth anchors found elsewhere in the book (接 = Lesson 1, confirmed from the
Lesson 1 生词 box on PDF p.13; 米 = Lesson 1, same source) plus semantic cross-checks
against lesson titles (解决 / 看来 → L11 "看来我没办法解决这个问题"; 来自 → L13 "我的新
邻居来自英国"). Confidence is good but not certain — if a build ever needs one of the
J/K/L/M words on this page, sanity-check its lesson number against the lesson's own
生词 box before trusting it blindly.

**Corrected against the 生词 boxes so far:** 了解 13 → 15 (Lesson 15 build); 楼梯 6 → 17,
留学 14 → 17, 留学生 17 → 14, 邻居 17 → 13 (Lesson 17 build — Lesson 17's box has 楼梯 ②
and 留学 ⑰, Lesson 14's has 留学生, Lesson 13's has 邻居).

**Added in QuizTool** (missing from the transcription, found in the lessons' 生词 boxes): 搬 L3 (box ㉕),
耳机 L6 (box ⑬), 而且 L7 (box ㉕; the Quick lookup table already had it), 耳朵 L8 (box ⑨).
