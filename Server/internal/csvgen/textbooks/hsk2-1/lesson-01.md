# 《HSK标准教程1》 Lesson 1 — 你好
English: Hello · Tiếng Việt: Xin chào

## New words
| Word | Pinyin | POS | English | Tiếng Việt | Note |
|---|---|---|---|---|---|
| 你 | nǐ | pron. | (singular) you | bạn; anh; chị | |
| 好 | hǎo | adj. | good, fine | tốt; khỏe | |
| 您 | nín | pron. | (polite) you | ông; bà; ngài (kính trọng) | ★ |
| 你们 | nǐmen | pron. | (plural) you | các bạn | |
| 对不起 | duìbuqǐ | v. | to be sorry | xin lỗi | |
| 没关系 | méi guānxi | | that's OK, it doesn't matter | không sao | |

## Language points
- Greetings: 你好 (to one person), 您好 (polite), 你们好 (to several people) / lời chào: 你好 (một người), 您好 (kính trọng), 你们好 (nhiều người).
- Apology and reply: 对不起 — 没关系 / xin lỗi và đáp lại: 对不起 — 没关系.

## Texts
### Text 1 — 你好
A：你好！
B：你好！

### Text 2 — 您好，你们好
A：您好！
B：你们好！

### Text 3 — 对不起，没关系
A：对不起！
B：没关系！
