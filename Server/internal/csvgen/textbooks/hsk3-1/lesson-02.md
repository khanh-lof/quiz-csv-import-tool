# 《新HSK教程1》 Lesson 2 — 我叫李文
English: My name is Li Wen · Tiếng Việt: Tôi tên là Lý Văn

## Objectives
- Understand and use Chinese names to introduce oneself.
- Understand and use apology expressions: say "对不起" to apologize and respond with "没关系".
- Master the basic word order in Chinese.
- Understand the structure of Chinese names (surname + given name).

## Language points
1. 汉语的基本语序 (Basic word order in Chinese) — Subject + Predicate + Object / Chủ ngữ + Vị ngữ + Tân ngữ. 例：我（主语）叫（谓语）陈天中（宾语）。　你叫什么名字？　我叫白家月。　我是学生。
2. 中国人的姓名 (Chinese names) — surname + given name / họ + tên. 例：我叫李文。
3. 礼貌用语 — 请问 is a polite expression used to ask someone to answer a question; 没事 / 没关系 answer an apology / "请问" dùng để hỏi lịch sự; "没事/没关系" đáp lại lời xin lỗi. 例：请问，你叫什么名字？　对不起！——没关系！

## Texts
### Text 1 — 在教室里，王一飞在认识学生。
王一飞：请问，你叫什么名字？
陈天中：我叫陈天中。

### Text 2 — 在校园里，陈天中和白家月打招呼时认错了人。
陈天中：你好，安妮！
白家月：你好，陈天中！我不是安妮，我是白家月。
陈天中：对不起！
白家月：没关系！

### Text 3 — 在校园里，李文和白家月第一次相遇。
李文：你好！我叫李文。
白家月：你好！我叫白家月。
李文：很高兴认识你。
白家月：认识你我也很高兴。
