# 《YCT标准教程1》 Lesson 10 — 现在几点？
English: What time is it? · Tiếng Việt: Bây giờ là mấy giờ?

## New words
| Word | Pinyin | POS | English | Tiếng Việt | Note |
|---|---|---|---|---|---|
| 现在 | xiànzài | | now | bây giờ | |
| 点 | diǎn | | o'clock | giờ | |
| 分 | fēn | | minute | phút | ★ |
| 见 | jiàn | | to meet | gặp | ★ |
| 早上 | zǎoshang | | morning | buổi sáng | ★ |

## Language points
1. 现在几点？ — asking the time with 几点 / hỏi giờ bằng 几点. 例：现在几点？
2. 明天5点见。 — time + 见, arranging when to meet / thời gian + 见, hẹn giờ gặp. 例：明天5点见。

## Texts
### Text 1 — Let's read：现在几点？
男孩：妈妈，现在几点？
妈妈：11点10分。
