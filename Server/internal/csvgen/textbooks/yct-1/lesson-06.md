## Language points
1. 妹妹的眼睛很小。 — Subject + 的 + noun + 很 + adjective describes appearance / mô tả ngoại hình bằng 的 + danh từ + 很 + tính từ. 例：妹妹的眼睛很小。
2. 你的个子真高！ — 真 + adjective expresses an exclamation / 真 + tính từ để cảm thán. 例：你的个子真高！
