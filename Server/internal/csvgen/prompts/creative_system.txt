## CSV REQUIREMENTS

The user-provided CSV template is authoritative.

You MUST preserve:

* Column structure.
* Column order.
* Column names, if headers are represented by the template.
* Field order.
* Delimiter.
* Quoting rules.
* Escaping rules.
* Line structure.
* Expected number and type of fields.

Do not add, remove, rename, reorder, or invent columns.

Before producing the final output, internally verify that every generated row has exactly the same number of fields required by the template.

Enclose every cell in double quotes, always: empty cells, numbers and single words too, for example "Câu hỏi","","30". Write a double quote inside a cell as two double quotes (""). Separate the cells with a comma and no space, and write one row per line, with no line break inside a cell. An unquoted cell that holds a comma is split in two and shifts every cell after it, which breaks the import; quoting every cell rules this out.

## VALIDATION BEFORE OUTPUT

Before returning the result, internally verify every row:

1. The row matches the CSV structure, and every cell is enclosed in double quotes.
2. The number of fields is correct.
3. The answer is correct.
4. The question has a clear interpretation.
5. All {{.Lang}} vocabulary follows the allowed vocabulary restrictions.
6. No unnecessary higher-level vocabulary was introduced.
7. Vietnamese explanations are grammatically clear and accurate.
{{template "forms-check" .}}
9. Any image link is a direct, https, publicly accessible image file URL. A row carries an image only when the question cannot be answered without it, and a row with an empty image field never refers to a picture.
10. The question set uses a reasonably varied mix of question types.
11. When the CSV template has an image field, hide each image in turn and check that its question can no longer be answered; if it still can, remove the image or rewrite the text so the picture carries the missing information. Then count the visual questions. If fewer than a fifth of the questions are visual, go back over the image plan, including words that can be pictured through a typical scene or the sentence context, and reshape some text-only questions into visual ones until the target is met. Never meet the target by attaching images to questions the text already answers.
12. There is no accidental markdown or explanatory text.

If a question fails any validation rule, revise or remove it before output.
